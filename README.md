# 像素魔导 · 语音施法练习场

一个纯前端的像素风小游戏：**大声念出咒语「操」，魔法师就会向稻草人释放魔法！** 连续念出咒语即可连续施法，每 10 连击触发终极魔法「星辰陨落」。

无需安装、无任何依赖、无外部资源 —— 打开 `index.html` 即可开玩。

## ✨ 特性

- 🎤 **语音施法**：基于浏览器 Web Speech API 实时识别咒语（含同音字容错），说出咒语即施法
- 🔊 **声控模式**：浏览器不支持语音识别时自动切换为音量检测模式，任意短促有力的声音即可施法
- ✨ **10 种法术 + 终极魔法**：炎爆术、雷霆万钧、冰霜棘刺、陨星天坠、奥术洪流、虚空奇点、圣光裁决、风暴龙卷、奥术飞弹、苍龙破，每 10 连击触发「星辰陨落」
- 🔥 **连击系统**：连续施法积累连击，实时统计总伤害、施法次数与单次最高伤害
- 🖥️ **低分辨率像素渲染**：168px 宽逻辑画布逐像素绘制，配合 Bayer 抖动渐变夜空、魔法阵、粒子特效与屏幕震动 / 闪光 / 顿帧打击感
- 🎵 **WebAudio 合成音效**：全部音效由代码实时合成，零音频文件
- 📱 **移动端适配**：竖屏 / 横屏自动布局，支持屏幕常亮（Wake Lock）
- 🪶 **零依赖**：纯 HTML + CSS + JavaScript，全部代码不到 2000 行

## 🚀 快速开始

### 本地运行

```bash
# 直接双击 index.html 也可以看画面，
# 但要使用语音识别，需在 HTTPS 或 localhost 下打开：
cd 项目目录
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

点击「✦ 开始施法 ✦」并**允许麦克风权限**，然后大声念出咒语「操」即可施法。

> 也可以直接点击画面或按空格键施法；语音识别不可用时会自动切换为「声控模式」。

### 浏览器要求

| 浏览器 | 语音识别 | 声控模式 |
| --- | --- | --- |
| Chrome（桌面 / Android） | ✅ | ✅ |
| Edge | ✅ | ✅ |
| Safari（macOS / iOS） | ✅ | ✅ |
| Firefox | ❌ | ✅ |

- 语音识别需要 **HTTPS 或 localhost** 环境及麦克风权限
- 语音识别依赖浏览器在线识别服务，网络不可用时自动降级为声控模式

## 🎮 操作方式

| 操作 | 效果 |
| --- | --- |
| 念出咒语「操」 | 释放随机法术（语音识别模式） |
| 发出短促有力的声音 | 施法（声控模式） |
| 连续念咒 | 连续施法，积累连击 |
| 每 10 连击 | 自动触发终极魔法「星辰陨落」 |
| 点击画面 / 按空格键 | 手动施法 |
| 灵敏度滑杆 | 调节声控模式的声音灵敏度 |

## 📁 项目结构

```
.
├── index.html       # 页面入口与 HUD / 开始界面
├── style.css        # 像素风 UI 样式
└── js/
    ├── main.js      # 主循环、布局适配、施法队列、HUD 与输入
    ├── core.js      # 渲染核心：低分辨率画布、像素绘制原语、粒子 / 魔法阵
    ├── voice.js     # 语音输入：Web Speech API 识别 + 声控模式降级
    ├── audio.js     # WebAudio 实时合成音效
    ├── spells.js    # 法术库：10 种法术 + 终极魔法的特效与伤害
    ├── world.js     # 场景：夜空背景、魔法师、稻草人、伤害数字
    └── sprites.js   # 像素精灵：字符画 → 离屏画布
```
